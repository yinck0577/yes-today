政府規劃自2027年推動「0至18歲成長津貼」，每名兒少每月5,000元。0至未滿6歲規劃全額由家庭使用；6至未滿18歲則採「一半提供家庭使用、一半存入兒少成長津貼專戶」設計。

相關經費已編入116年度中央政府總預算，但預算程序仍待完成。目前尚未開放申請，也沒有正式發放起始月份與申請方式，因此不能把政策目標直接解讀為2027年1月1日一定入帳。

## 三大重點先看

- **每人每月5,000元：**政策對象規劃為0至未滿18歲兒少。
- **6歲是分流點：**0至未滿6歲全額由家庭使用；6至未滿18歲則為2,500元家庭使用、2,500元存入專戶。
- **現在還不能申請：**確切發放月份、資格細節、申請網站及專戶開立方式仍待主管機關公告。

## 0至18歲成長津貼5000元確定了嗎？

政策已正式公布，經費也已編入116年度中央政府總預算，但立法院尚未完成預算審議，目前不能申請。

總統府今年5月公布「台灣人口對策新戰略－家庭支持篇」，明確提出0至未滿18歲每人每月5,000元成長津貼。行政院隨後通過政策方案，並規劃自116年、也就是2027年起實施。

政府最新說法指出，0至18歲成長津貼不需要另行立法，相關經費已編入116年度總預算。不過，總預算仍須完成立法院審議，主管機關也須公布實際執行辦法。

| 2027成長津貼最新進度 | 狀態 |
| --- | --- |
| 政策已宣布 | 是 |
| 金額 | 每人每月5,000元 |
| 對象 | 0至未滿18歲兒少 |
| 經費編入116年度總預算 | 是 |
| 立法院完成預算審議 | 尚未 |
| 現在能申請 | 不能 |
| 申請方式 | 尚未公布 |
| 確切開始月份 | 尚未公布 |

目前能確定的是政策設計與預算方向，還不能把「2027年」直接寫成「2027年1月1日開始入帳」。

## 2027成長津貼誰能領？完整資格公布了嗎？

目前已確定的政策對象是0至未滿18歲兒少，但完整行政資格仍待正式發放辦法。

政府尚未完整公布的細節包括：

- 新生兒從出生當月或次月起算。
- 滿18歲的資格截止基準。
- 戶籍或居留條件。
- 海外兒少是否適用。
- 外籍家庭或特殊身分兒少如何認定。
- 是否需要另外申請。
- 由哪一名家長或照顧者提出申請。

因此，「0至未滿18歲」是目前明確的政策範圍，但不能自行替政府補上尚未公布的身分與申請資格。

行政院現行政策說明指出，0至未滿6歲的5,000元，規劃匯入申請人，例如監護人、實際照顧者或兒童本人帳戶；6至未滿18歲則有部分資金進入兒少專戶。

## 0至6歲怎麼發？每月5000元全額給家庭

依目前規劃，0至未滿6歲兒童的每月5,000元成長津貼，全額交由家庭使用。

換句話說：

**0至未滿6歲：每月5,000元 → 全額由家庭使用。**

這和6歲以後的「半存半領」制度不同，也是理解這項政策最重要的年齡分界。

## 0至6歲原有育兒津貼、托育補助還能領嗎？

依政府目前規劃，可以疊加，不會因新增成長津貼就取消原有0至6歲支持措施。

總統府表示，新增加的0至18歲成長津貼將與現行「0到6歲國家一起養2.0」政策疊加實施。既有措施包括：

- 育兒津貼。
- 公共化托育補助。
- 準公共托育補助。
- 公立幼兒園。
- 非營利幼兒園。
- 準公共幼兒園等幼教支持。

例如目前自行照顧、符合第一胎育兒津貼資格的0至2歲幼兒，每月育兒津貼為5,000元；若新成長津貼最終依目前方案實施，兩者在這項特定情境下合計可達每月1萬元。

但不同托育方式與家庭原本適用的補助不同，不能簡化成「2027年所有0至6歲兒童每月都直接領1萬元」。

## 6至18歲也是每月領5000元現金嗎？

不是。依目前規劃，6至未滿18歲採「2,500元家庭使用＋2,500元存入兒少專戶」。

| 年齡 | 每月5,000元怎麼分 |
| --- | --- |
| 0至未滿6歲 | 5,000元全額由家庭使用 |
| 6至未滿18歲 | 2,500元家庭使用＋2,500元存入兒少成長津貼專戶 |

行政院規劃，進入專戶的2,500元由國家提撥預存，並交由專業金融團隊管理投資，政府承擔投資風險，至少保障2年期定期存款利率；孩子滿18歲後，再領出專戶資金。

一名6至未滿18歲兒少每年的名目成長津貼為：

**5,000元 × 12個月＝6萬元**

其中約3萬元供家庭當年度使用，另外3萬元進入兒少專戶累積。因此，不能把「6至18歲每月5,000元」直接理解成家長帳戶每月會收到5,000元。

## 從0歲領到18歲總共有多少？

政府官方資料以「從0歲開始，最少108萬元」說明整體政策規模，計算概念是：

**5,000元 × 12個月 × 18年＝108萬元**

但這不代表孩子滿18歲時可以一次領到108萬元。

- 0至未滿6歲的成長津貼已在成長過程中由家庭每月使用。
- 6至未滿18歲的一半持續由家庭使用。
- 6至未滿18歲的另一半才會累積在兒少專戶。

總統府進一步說明，6至18歲每月存入2,500元，12年本金約36萬元，再加上政府管理投資所產生的收益，才是孩子滿18歲後可領出的專戶資金。

因此，108萬元是0至18歲整體成長津貼的名目總額，不是一筆108萬元的成年禮。

## 成長津貼5000元什麼時候開始？

政策規劃自2027年實施，但目前尚未公布確切開始發放月份。

目前時間線可以這樣看：

**2026年5月：公布0至18歲成長津貼政策**

**→ 2026年8月：相關經費編入116年度中央政府總預算**

**→ 立法院審議總預算**

**→ 主管機關公布資格、專戶及發放辦法**

**→ 正式開始發放**

政府表示政策預計自116年起實施，但這仍不能進一步解讀為「2027年1月1日一定入帳」。

尤其6至18歲制度涉及兒少個人專戶、金融管理及行政系統建置；即使總預算通過，主管機關仍須完成相關執行辦法與系統準備。

## 成長津貼怎麼申請？需要登記嗎？

目前尚未公布。

截至8月22日，政府已公布成長津貼年齡、金額及0至6歲、6至18歲的資金分配方式，但完整申請流程還沒出爐。

目前仍待公告：

- 是否自動核發。
- 是否需要家長線上登記。
- 申請網站。
- 要準備哪些資料。
- 0至6歲匯入哪個帳戶。
- 6至18歲兒少專戶如何開立。
- 新生兒如何加入制度。
- 發放日與入帳頻率。

如果現在看到要求家長「登記2027成長津貼」的非官方網站，不要先提供個資或金融帳戶。後續正式辦法公布後，申請資訊將是最需要優先更新的內容。

## 116年度人口政策還有哪些措施？

0至18歲成長津貼只是「台灣人口對策新戰略－家庭支持篇」的一部分。政府另規劃生育給付、托育、教育、職場育兒及居住支持等措施。

不過，各項措施涉及的法律、預算及施行日期並不完全相同，不能因為都納入2027年度政策方向，就認定全部會在2027年1月1日同步生效。

對有孩子的家庭而言，目前最值得先記住的3件事是：

**0至未滿6歲每月5,000元全額給家庭；6至未滿18歲每月2,500元家庭使用、2,500元進專戶；正式申請與發放時間仍待公告。**
