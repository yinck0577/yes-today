[OKmart](https://www.okmart.com.tw/)被美廉社母公司[三商家購](https://www.simplemartretail.com/)收購後，第一家新形象店正式曝光。新北市板橋大仁店從過去的紅白招牌改為藍白新Logo，店內同步導入電子價卡，並增加韓國零食、冷藏商品與家庭用品。據媒體現場訪問店員，大仁店自9月18日起換上新裝。

不過，換Logo只是這場改造的第一步。三商家購2026年以1.25億元收購來來超商（OKmart）100%股權及經營所需的相關智慧財產權，完成交易後，來來超商更名為富達零售並成為三商家購100%持股子公司；如今三商家購規劃再投入約4.5億元，改造200多家開放型OK門市，並以2027年OK整體轉虧為盈為目標。

## OK超商新Logo長怎樣？紅白招牌改成藍白色

目前率先曝光的是新北市**板橋大仁店**，也是這波改造的首家新形象店。

最明顯的改變，就是過去使用多年的紅白品牌色退場，改成藍白配色；新版招牌仍保留「OK」字樣，旁邊則加入新的圖像Logo。三商家購已於9月7日向經濟部提出新款藍白Logo商標申請，目前案件仍在辦理中。

至於新Logo被網友形容「像魚」、「像冰品店」，或聯想到日本便利商店LAWSON，目前都屬於社群對外觀的觀察。OKmart與三商家購尚未正式公開新Logo的完整設計理念，因此不宜直接把「魚」寫成官方Logo意象。

## OK超商收購後改了什麼？電子價卡、進口商品陸續導入

**不只招牌換顏色，商品與門市設備也開始調整。**

目前板橋大仁店已可看到電子價卡，商品方面則增加韓國零食、冷藏商品，以及洗衣精、洗碗精等家庭用品；貨架與空間配置也同步調整。

這些變化其實與三商家購5月公布的整合方向一致。三商家購當時提出「智慧零售擴大應用、商品與服務互導、破圈展店、營業模式調整」四大策略，包括把電子價卡導入OK、引進自辦進口及自有品牌商品，並依不同門市需求調整營業時間與商品結構。

因此，大仁店現在出現的電子價卡與商品結構調整，可以視為先前整合策略開始落地，但三商家購目前仍採雙品牌經營，並未宣布把OK直接改成美廉社。

## 美廉社真的買下OK了嗎？其實是母公司三商家購收購

**嚴格來說，買下OKmart的不是美廉社，而是美廉社母公司三商家購。**

三商家購1月23日董事會通過，以1.25億元收購**來來超商100%股權及經營所需的相關智慧財產權**；3月13日取得公平會不禁止結合的審查結果，3月27日完成交易，並自當日起將富達零售營收納入三商家購合併報表。

| 時間 | OK超商收購與改造進度 |
|---|---|
| **1/23** | 三商家購宣布1.25億元收購來來超商100%股權及相關智慧財產權 |
| **3/13** | 公平會審查通過 |
| **3/27** | 完成交易，富達零售開始納入三商家購合併營收 |
| **5月** | 三商家購公布OK整合四大策略 |
| **9/7** | 三商家購申請OK藍白新Logo商標 |
| **9月** | 板橋大仁店新形象曝光 |
| **2027 Q2前** | 主要既有開放型門市改造完成目標 |
| **2027 Q3** | 規劃重新啟動展店 |
| **2027年** | OK整體轉虧為盈目標 |

## 三商家購為什麼花1.25億元收購OK超商？

對三商家購而言，這筆交易的價值不只是一個「OK」品牌名稱，更重要的是透過取得來來超商100%股權，直接納入既有OKmart營運體系、門市與加盟網絡，另取得經營所需智慧財產權，不必從零建立數百個據點。

三商家購總經理邱光隆9月接受專訪時指出，如果重新尋找300、400個據點，再逐一建立人力與加盟體系，可能需要多年時間；他因此將這次收購的價值形容為省下建立通路網絡所需的「歲月」。

收購完成後，三商家購旗下社區零售總店數在3月底已達**1,219家**；集團後續又將長期展店目標從原先約1,300家提高到**2,200家**，希望2030年達成。

## 三商家購要花4.5億元改OK？哪些門市會改？

**不是全台OK門市都會使用同一種方式翻新。**

依邱光隆最新公布的規劃，目前全台約有100多家OK位於封閉型商圈，這類門市原有模式可以獲利，原則上不進行大幅改造；主要翻新的對象，是另外**200多家開放型門市**。

三商家購**規劃投入約4.5億元**，針對開放型門市調整店招、動線、設備與商品結構，同時導入電子價卡。既有門市的主要改造目標是在2027年第2季以前完成，2027年第3季再重新啟動展店。

| OK改造計畫 | 最新規劃 |
|---|---|
| **封閉型商圈門市** | 100多家，原則上不大幅改裝 |
| **主要改造門市** | 200多家開放型門市 |
| **規劃資本支出** | 約4.5億元 |
| **改造內容** | 店招、動線、設備、商品結構、電子價卡 |
| **主要改造完成目標** | 2027年第2季前 |
| **重新展店** | 規劃2027年第3季啟動 |
| **OK整體獲利目標** | 2027年轉虧為盈 |

因此，目前板橋大仁店比較接近第一批新店型測試，不能理解成全台OK都已經換成藍白招牌。

### 改裝後要達到什麼？來客＋35%、第3個月獲利都是目標

三商家購也為改裝店設定測試KPI：**來客數較改裝前成長35%，並力拚改裝後第3個月開始獲利**；如果未達目標，再回頭調整商品與店型。

這兩項數字目前都是三商家購設定的**改裝目標**，並不是板橋大仁店已經達成的實際成績。

## 兩個4.5億元別搞混：美廉社電子價卡、OK改裝是兩筆投資

三商家購近年剛好有**兩筆約4.5億元的零售投資**，很容易被混在一起。

> **第一筆是美廉社約300萬張電子價卡，第二筆才是OK超商200多家開放型門市的改造計畫。**

美廉社的電子價卡投資約4.5億元，在全台800多間門市導入約300萬張電子價卡，並已於2025年7月完成全面部署；三商家購2026年也表示，未來將把這套智慧零售基礎建設延伸到OK。

| 約4.5億元投資 | 用途 | 進度 |
|---|---|---|
| **美廉社電子價卡** | 800多家門市、約300萬張電子價卡 | 2025年7月完成全面部署 |
| **OK門市改造** | 200多家開放型門市翻新 | 規劃執行中，目標2027 Q2前完成主要改造 |

因此，看到「三商家購4.5億元投資」時，要先確認談的是已完成的美廉社電子價卡，還是最新的OK改造計畫。

## 買下OK後財報變怎樣？營收大增、Q2 EPS降至0.03元

OK從3月27日起正式納入三商家購合併報表，因此第一季只有約5天受到併購影響，第二季才是第一個較完整反映OK併表的季度。三商家購第1季營收38.37億元、EPS 0.54元；第2季營收則增加至**50.78億元**，但EPS降至**0.03元**。

| 財報指標 | 2026 Q1 | 2026 Q2 |
|---|---:|---:|
| **合併營收** | 38.37億元 | **50.78億元** |
| **EPS** | 0.54元 | **0.03元** |
| **OK併表程度** | 約5天 | 首個較完整季度 |

其中財報口徑要特別區分。依2026年第2季合併財報，三商家購單季**本期淨損49萬元**，但歸屬母公司業主淨利為**177.7萬元**，因此單季EPS仍為0.03元；去年同期EPS則為0.43元。2026上半年歸屬母公司業主淨利3,834.1萬元，累計EPS為0.57元。

## 為什麼營收增加，獲利沒有同步成長？

從財報可以確認的是，**OK較完整併表後，三商家購營收規模與營業費用都明顯增加**。

2026年第2季營收由去年同期36.40億元增加至50.78億元；同期推銷費用由約8.33億元增加至11.47億元，管理費用由約1.13億元提高至1.90億元，毛利率則由26.94%小幅降至26.65%。

但這些數字**不能直接解讀成「Q2獲利下降都是OK造成」**。公開合併財報呈現的是整個集團數字，沒有把上述費用與獲利變化全部拆成「OK貢獻多少、美廉社貢獻多少」。

因此，目前較精確的判讀是：**OK完整併表後，營收規模明顯放大，但獲利尚未同步成長；至於各項獲利變化有多少直接來自OK，現有公開合併財報不足以完整拆分。**

## 三商家購前8月營收125億元，代表美廉社成長近3成嗎？

**不能這樣解讀。**

三商家購官方月營收資料顯示，2026年前8月合併營收約**125.16億元，年增28.89%**；其中4月至8月單月年增率依序達38.55%、40.92%、39.09%、42.15%與35.29%。

但三商家購官方同一份資料也明確註明，3月27日取得富達零售100%股份後，就開始把該子公司營收納入合併報表。

也就是說，4月以後三商家購出現約35%至42%的高年增率，**包含OK併購後合併範圍改變的效果，不等於美廉社既有門市本身突然成長4成，也不能直接當成同店營收成長率。**

這也是閱讀三商家購2026年財報時最需要注意的地方：**營收規模變大已經很明顯，但真正要判斷併購成效，還得繼續看獲利、單店表現與改裝後來客數。**

## OK超商以後會變成美廉社嗎？

**不會直接改成美廉社，目前三商家購仍採OKmart、美廉社雙品牌策略。**

三商家購1月宣布收購時就表示，交易完成後雙方仍維持既有品牌與通路定位；5月公布的整合策略也以商品、服務、智慧零售與展店場景「互導」為主，而不是把兩個品牌合併。

從板橋大仁店目前的商品配置來看，可以看到家庭用品、冷藏商品與進口零食比重增加，呈現更多超市型商品特徵；但三商家購目前尚未正式把OK定義成「超商＋超市」的新業態。

因此，較精確的理解不是「OK變成美廉社」，而是兩個品牌開始共享部分商品、設備與營運資源。

## OK超商以後都還是24小時嗎？

**不一定，未來不是所有OK門市都一定維持相同的24小時營業模式。**

三商家購5月法說會已表示，OK後續將依個別門市需求，彈性調整24小時營運服務與商品結構。

但目前公司沒有公布哪些特定門市會縮短營業時間，因此不能直接推論「住宅區OK未來都不開24小時」。實際營業時間仍要依個別門市後續公告為準。

## OK超商什麼時候可能轉虧為盈？

**三商家購目前設定的目標是2027年讓OK整體轉虧為盈。**

按照目前規劃，2026年先以新店型進行改造測試；2027年第2季以前完成主要既有開放型門市改造，第3季再重新啟動展店。改裝店則以來客數成長35%、改裝後第3個月開始獲利為測試目標。

整場收購與改造可以濃縮成：

| 階段 | 三商家購、OK主要動作 |
|---|---|
| **2026 Q1** | 1.25億元收購、3/27完成交易並開始併表 |
| **2026 Q2** | 公布雙品牌四大整合策略；Q2 EPS 0.03元 |
| **2026 Q3** | 藍白新Logo與首家新形象店曝光 |
| **2026～2027 Q2** | 規劃投入約4.5億元改造200多家開放型門市 |
| **2027 Q3** | 規劃重新啟動OK展店 |
| **2027全年** | **OK整體轉虧為盈目標** |
| **2030** | 三商家購長期總店數目標2,200家 |

因此，現在看到的藍白新Logo只是收購後最先被消費者注意到的改變。對三商家購而言，接下來更關鍵的數字會是**200多家門市改裝後的來客數、單店損益，以及OK能否如期在2027年轉虧為盈**。
