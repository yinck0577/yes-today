如果在日治時期的台灣地圖、老照片或明信片上看到「Taihoku」，它指的其實就是**臺北**。

日治時期，「臺北」的漢字並沒有改掉，日語讀作「たいほく（Taihoku）」，因此英文或羅馬字資料常會出現Taihoku。換句話說，Taihoku不是另一座城市，也不是日本統治台灣後重新取了一個叫「Taihoku」的地名，而是「臺北」在當時日語環境中的讀法與羅馬字表記。

更有趣的是，「臺北」這個名字本身也不是日本統治台灣後才出現。

從清代文獻中的「臺北」，到1875年的「臺北府」、1895年後的臺北縣，再到1920年的臺北州與臺北市，今天我們熟悉的「台北」，其實經歷過不同時代的行政變化。

## Taihoku是什麼？就是「臺北」的日語讀音

先說最簡單的答案：

**Taihoku＝臺北。**

日治時期「臺北」寫成漢字仍是「臺北」，日語讀作「たいほく」，以羅馬字表示時便會看到「Taihoku」。

因此，在當時的英文地圖、明信片、鐵路資料或外文文獻裡，都可能看到Taihoku。

例如：

| 當時漢字 | 日語讀音 | 常見羅馬字 |
|---|---|---|
| 臺北 | たいほく | Taihoku |
| 臺中 | たいちゅう | Taichū |
| 臺南 | たいなん | Tainan |

所以，如果在一張日本時代的老照片上看到「Taihoku Station」，指的就是臺北車站；看到「Taihoku City」，則是在說臺北市。

它和今天國際上使用的「Taipei」，指向的是同一座城市，只是出現在不同時代、不同語言系統之下。

## 台北以前叫什麼？其實要分「地區名稱」和「城市名稱」

搜尋「台北以前叫什麼」時，很容易得到一個過度簡化的答案：

**台北以前叫Taihoku。**

這句話不能算完全錯，但並不精確。

因為Taihoku本身就是「臺北」的日語讀音，不是把「臺北」換成另一個完全不同的名字。

如果再往前追，今天的臺北市也不是自古就以「臺北」作為一座城市的正式名稱。

清代臺北盆地已經存在艋舺、大稻埕等聚落；「臺北」一詞早期則曾用來泛指臺灣北部地區。

臺北市政府資料指出，清康熙末、雍正初藍鼎元的《紀竹塹埔》中，就已經可以看到「臺北」一詞，當時所指的是竹塹，也就是今日新竹以北的臺灣北部地區。

因此，「臺北」兩字的歷史其實比日治時期早了將近兩個世紀。

## 「臺北」什麼時候正式成為行政名稱？關鍵是1875年

真正重要的轉折發生在1875年。

1874年牡丹社事件後，清廷重新重視臺灣的海防與治理。欽差大臣沈葆楨奏請調整臺灣行政區劃，在北部增設「臺北府」。

1875年，也就是清光緒元年，臺北府設置。

這是「臺北」成為正式行政區名稱的重要節點。

當時的臺北府範圍遠比今天的臺北市大，下轄淡水縣、新竹縣、宜蘭縣及基隆廳等區域。

之後臺北府城逐步興建，1884年完工；臺灣建省後，首任巡撫劉銘傳也以臺北府城作為重要政治中心。

1894年，臺灣省會正式移至臺北，臺北的政治地位進一步提高。

因此，如果問「台北這個名字是不是日本人取的？」

答案是：

**不是。**

「臺北」一詞在清代早已存在，1875年更正式成為「臺北府」的行政名稱。

## 1895年日本統治後，「臺北」也沒有消失

1895年日本開始統治臺灣後，原本的臺北府遭到廢除，行政制度經歷多次調整。

但「臺北」這個名稱並沒有被捨棄。

日治初期曾設置「臺北縣」，之後又歷經臺北廳等行政區劃。

到了1920年，臺灣地方制度進行大規模改制，全臺劃分為五州二廳，「臺北州」正式成立；同時設置「臺北市」，隸屬於臺北州。

也就是從1920年開始，「臺北市」正式成為行政區名稱。

簡單整理台北名稱的演變：

| 時間 | 名稱／變化 |
|---|---|
| 清康熙末至雍正初 | 文獻已出現「臺北」，泛指竹塹以北 |
| 1875年 | 清廷設「臺北府」 |
| 1884年 | 臺北府城興築完成 |
| 1894年 | 臺灣省會移至臺北 |
| 1895年 | 日本統治初期設「臺北縣」 |
| 日治中期 | 歷經「臺北廳」等行政制度 |
| 1920年 | 設「臺北州」與「臺北市」 |
| 1945年後 | 「臺北市」名稱繼續沿用 |

所以，從歷史脈絡來看，比起「台北以前叫Taihoku」，更準確的說法應該是：

**日治時期的臺北，在日語中讀作Taihoku。**

## Taihoku和Taipei為什麼差這麼多？

既然漢字都是「臺北」，為什麼Taihoku和今天的Taipei看起來完全不像？

關鍵在於語言不同。

Taihoku來自「臺北」兩字的**日語讀音**：

臺（たい／tai）＋北（ほく／hoku）＝たいほく（Taihoku）

而今天國際通行的Taipei，則來自漢語「臺北」的羅馬字拼寫傳統。

因此，Taihoku與Taipei不是兩個不同地名，而是同一組「臺北」漢字在不同語言與羅馬字系統下形成的名稱。

這也解釋了為什麼日治時期其他台灣城市會出現Taichū、Heitō、Karenkō等今天看起來陌生的英文拼法。

## 臺北市和臺北州一樣嗎？範圍差很多

另一個容易混淆的名稱是「臺北州」。

1920年至1945年間，同時存在「臺北州」和「臺北市」，但兩者不是同一個行政區。

**臺北市（Taihoku City）**是城市。

**臺北州（Taihoku-shū／Taihoku Prefecture）**則是更大的行政區，州治設在臺北市。

臺北州的範圍包括當時的臺北市、基隆市、宜蘭市，以及七星、淡水、基隆、宜蘭、羅東、蘇澳、文山、海山、新莊等郡，大致涵蓋今天的臺北市、新北市、基隆市與宜蘭縣等區域。

因此，看到歷史資料中的「Taihoku Prefecture」，通常是在指臺北州；「Taihoku City」才是臺北市。

## 日治時期台灣其他城市叫什麼？

Taihoku不是唯一在日治資料中出現不同讀法的台灣地名。

有些地方保留原本漢字，但按照日語音讀；有些則牽涉舊地名改寫與原有發音。

常見例子包括：

| 今日名稱 | 日治時期漢字 | 當時讀音／羅馬字 |
|---|---|---|
| 台北 | 臺北 | Taihoku |
| 台中 | 臺中 | Taichū |
| 台南 | 臺南 | Tainan |
| 高雄 | 高雄 | Takao |
| 屏東 | 屏東 | Heitō |
| 花蓮 | 花蓮港 | Karenkō |
| 宜蘭 | 宜蘭 | Giran |

不過，不能拿今天所有台灣縣市名稱直接套用日語音讀，就認為那是日治時期的正式名稱。

例如今天的「新北市」直到2010年才成立，日治時期並不存在同層級、同範圍的「新北市」，因此把新北直接讀成「Shinhoku」只能算現代依日語音讀做出的推演，不能當成當時的正式城市名稱。

## 高雄為什麼叫Takao？和Taihoku的情況不一樣

高雄是另一個很有代表性的例子。

高雄舊稱「打狗」，日語以「たかお（Takao）」稱呼。1920年地方制度改制時，「打狗」改以漢字「高雄」書寫，但仍沿用Takao的讀法。

因此，高雄和臺北的情況並不完全相同。

臺北是既有「臺北」漢字在日語環境下讀成Taihoku；高雄則涉及「打狗」到「高雄」的地名改寫，同時保留Takao這個讀音。

這也是為什麼不能只拿今天的漢字，用現代日語逐字音讀，就推斷日治時期一定這樣稱呼。

## 基隆、宜蘭的讀音也和今天想像的不太一樣

基隆也是值得注意的例子。

「基隆」這個名稱本身並非日本統治後才出現。清代原有「雞籠」之稱，1875年設置臺北府時，改以同音且帶有「基地昌隆」意涵的「基隆」為名。

到了日治時期，基隆可見「キールン／Kīrun」等表記。

宜蘭則可見「ぎらん（Giran）」的讀法。

這些例子都提醒我們：歷史地名的讀法往往混合了漢字、地方既有發音、日語轉寫及不同時代的行政制度，不能只靠今天的日文漢字讀音逆推。

## 台北市內也曾有「大宮町、乃木町、表町」

如果把地圖再放大，日治時期臺北不只有Taihoku這個城市讀音，市區地址也和今天非常不同。

1922年臺北實施町名改正，市區劃分出大量「町」。

當時可以看到：

大宮町、水道町、乃木町、兒玉町、佐久間町、表町、大橋町等名稱。

其中部分町名來自公共設施、地理位置或日本人物名稱，也有部分原有地名繼續使用。

國立臺灣歷史博物館典藏的臺北表町老明信片，就可以看到「Omotemachi Street, Taihoku」的英文標示。

也就是：

**Omotemachi＝表町**

**Taihoku＝臺北**

一張百年前的明信片地址，其實同時保存了城市名稱、町名與當時的羅馬字使用方式。

## 為什麼現在搜尋Taihoku，還是會看到很多台灣老照片？

因為Taihoku曾廣泛出現在日治時期與外文資料中。

當時的地圖、明信片、觀光資料、交通紀錄、建築資料及外文出版品，都可能使用Taihoku表示臺北。

因此今天在博物館數位典藏、海外圖書館、古地圖或老明信片拍賣資料庫搜尋「Taihoku」，經常比只搜尋「Taipei」更容易找到日治時期臺北的史料。

同樣地，如果想找其他城市的歷史影像，也可以嘗試使用當時名稱或羅馬字搜尋，例如「Taichu Taiwan」、「Takao Taiwan」等。

對查找老照片的人而言，城市曾經使用過的外文名稱，就像一把通往不同資料庫的鑰匙。

## Taihoku常見問題

### Taihoku是哪裡？

Taihoku就是臺北。「臺北」在日治時期日語讀作「たいほく」，羅馬字常寫成Taihoku。

### 台北以前真的叫Taihoku嗎？

可以這樣理解，但更精確地說，Taihoku是「臺北」的日語讀音及羅馬字表記，漢字仍然寫作「臺北」，並非改成另一個完全不同的地名。

### 台北這個名字是日本人取的嗎？

不是。「臺北」一詞在清代文獻中已經出現，1875年清廷設置「臺北府」，比1895年日本開始統治臺灣早20年。

### 台北市什麼時候出現？

1920年日本統治時期實施地方制度改制，設置臺北州及州轄臺北市，「臺北市」正式成為行政區名稱。

### 臺北州就是現在的臺北市嗎？

不是。臺北州的範圍比臺北市大得多，大致涵蓋今天臺北市、新北市、基隆市、宜蘭縣等地；臺北市只是臺北州所轄城市之一，也是州治所在地。

### Taihoku和Taipei有什麼不同？

兩者都指臺北。Taihoku來自「臺北」的日語讀音；Taipei則是後來國際通行的漢語羅馬字拼寫。

### 日治時期台中叫什麼？

「臺中」當時仍寫作臺中，日語讀作「たいちゅう」，羅馬字常寫作Taichū。

### 日治時期高雄叫什麼？

高雄常見讀音為Takao。高雄舊稱「打狗」，1920年改以「高雄」二字書寫後，仍沿用Takao的讀音。
