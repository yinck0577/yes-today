台北市政府8月19日公布，預計自2027年推出「月子加菜金—產後膳食費補助」，每位產婦不排富、每胎補助3萬元，預估每年約1.1萬名產婦受惠。這項補助目前仍在政策公布階段，正式申請資格、設籍條件、申請時間與領取方式都還沒公布，現在也還不能申請。除了月子加菜金，台北市同步公布好孕2U加碼、新生兒免費臨托券與醫療性凍卵補助等婚育措施，但各項上路時間不同。

## 三大重點先看

- **金額與對象**：每位產婦不排富、每胎補助3萬元。
- **上路時間**：預計2027年推出，目前尚未開放申請。
- **細節待公布**：設籍條件、申請方式與時間都還沒公布。

## 台北月子加菜金是什麼？每胎補助3萬元

「月子加菜金」正式名稱為「月子加菜金—產後膳食費補助」，是台北市政府8月19日新公布的婚育政策。依目前官方資訊，補助規劃如下：

| 台北月子加菜金 | 目前公布內容 |
| --- | --- |
| 補助金額 | 每胎3萬元 |
| 是否排富 | 不排富 |
| 預計上路 | 2027年 |
| 預估受惠人數 | 每年約1.1萬名產婦 |
| 完整申請資格 | 尚未公布 |
| 申請方式 | 尚未公布 |
| 申請時間 | 尚未公布 |

官方目前使用的是「每位產婦不排富、每胎補助3萬元」的表述。至於雙胞胎、多胞胎如何計算，正式辦法尚未公布，因此現階段不宜自行推定實際核發方式。

## 月子加菜金2027什麼時候開始？現在可以申請嗎？

還不能申請，目前市府只宣布預計2027年推出。截至8月19日，台北市政府尚未公布月子加菜金的正式申請網站、受理日期、申請文件及撥款方式。

因此，目前網路如果出現「月子加菜金開始登記」、「3萬元申請入口」等訊息，都應先確認是否來自台北市政府正式公告。後續最值得持續追蹤的資訊包括：

- 正式上路日期
- 設籍條件
- 生產日期認定
- 申請期限
- 申請網站
- 撥款方式
- 多胞胎如何計算

## 台北月子加菜金誰能領？要設籍多久？

目前只確認不排富、每胎補助3萬元，完整資格還沒公布。截至8月19日，市府尚未說明下列細節：

| 常見資格問題 | 目前答案 |
| --- | --- |
| 是否須設籍台北市？ | 待正式辦法 |
| 要設籍多久？ | 待正式辦法 |
| 2026年底生產能否申請？ | 待正式辦法 |
| 外籍配偶是否適用？ | 待正式辦法 |
| 是否有所得限制？ | 已宣布不排富 |
| 雙胞胎如何計算？ | 待正式辦法 |

這裡不建議直接套用台北市現行生育獎勵金的設籍規則，因為兩者屬於不同補助；正式辦法公布以前，不能假設資格一定完全相同。

## 月子加菜金和生育獎勵金一樣嗎？

不一樣，月子加菜金是新增的產後膳食費補助。台北市原本已有生育獎勵金，目前第一胎生育獎勵金為4萬元；這次公布的月子加菜金是額外新增的3萬元補助，並不是把原本生育獎勵金改名。

若依目前公布政策，第一胎家庭未來若同時符合生育獎勵金及月子加菜金資格，相關補助總額可能提高；但實際能否同時請領及適用資格，仍應以2027年月子加菜金正式辦法為準。

## 台北2026、2027還有哪些婚育新制？

除了月子加菜金，台北市8月19日也同步公布其他婚育措施，實施時間各不相同，可以先作為延伸資訊掌握。

### 好孕2U加碼至1萬點

「好孕2U」專車補助將從現行8,000點提高到1萬點，市府估計約可增加8趟搭乘機會；使用期限也由原本產後半年延長至預產期後1年。新制預計2026年10月實施，屆時新申請者及仍在有效期限內的使用者都可適用，預估約1.2萬名孕產婦受惠。

### 新生兒8小時免費臨托券

北市規劃2026年9月推出8小時免費電子臨托券。依目前公布條件，台北市民家中若有2026年出生、申請時滿6個月以上未滿1歲的新生兒，可依後續公告申請，取得後可使用至幼兒滿2歲前，屆時透過社會局指定平台提出申請。

### 醫療性凍卵最高補助7.2萬元

台北市也規劃自2027年1月擴大醫療性凍卵補助。補助對象預計擴大至25至40歲、因疾病本身或治療可能影響生育能力的女性；補助最高提高至7萬2,000元，其中療程補助最高6萬元，另有4年保存費共1萬2,000元。

## 台北婚育新制何時上路？時間表一次看

這次公布的政策並非同一天實施，從2026年9月一路排到2027年，部分措施甚至仍待法制程序。

| 政策 | 主要內容 | 預計上路 |
| --- | --- | --- |
| 新生兒電子臨托券 | 8小時免費臨托 | 2026年9月 |
| 好孕2U PLUS | 8,000點提高至1萬點 | 2026年10月 |
| 新手家庭特別門診 | 最長60分鐘跨專業門診 | 2026年10月 |
| 月子加菜金 | 每胎3萬元、不排富 | 2027年 |
| 醫療性凍卵 | 最高補助7.2萬元 | 2027年1月 |
| 婚育家庭房地稅 | 以地價稅、房屋稅減至0元為政策目標 | 尚未生效，待法制程序 |

其中「婚育家庭房地稅減至0元」目前仍屬政策目標，市府表示要等待相關法制推動、條件完備後再落實，因此現在不宜寫成「2027年台北婚育家庭免房屋稅」已經確定實施。

## 常見問題

### 月子加菜金現在能申請嗎？

不能。目前只公布政策方向，預計2027年上路，正式申請管道尚未公布。

### 月子加菜金會排富嗎？

不會。官方表示每位產婦不排富、每胎補助3萬元。

### 月子加菜金和生育獎勵金可以一起領嗎？

目前公布的是兩項不同補助，實際能否同時請領及適用資格，仍須以2027年正式辦法為準。

### 雙胞胎、多胞胎補助怎麼算？

尚未公布，正式辦法出爐前不宜自行推定核發方式。
