因景氣及國際經貿情勢受到影響而實施減班休息，符合資格的勞工可申請薪資補貼。勞動部8月10日宣布，9大製造業「僱用安定措施」再延長3個月至2026年10月底，補貼依減班前後薪資差額的70%計算，每人每月最高11,500元。

不過，公司實施俗稱「無薪假」的減班休息，不代表勞工一定符合補貼資格，所屬行業、減班期間、通報及就業保險等條件都會影響能否請領。

## 三大重點先看

- **延長時間**：9大製造業僱用安定措施延長至2026年10月底。
- **補貼金額**：減班前後薪資差額的70%，每人每月最高11,500元。
- **不是自動領取**：公司實施減班休息後，勞工仍須符合行業、期間、通報與投保等條件。

## 無薪假補貼延長到什麼時候？

9大行業僱用安定措施已再延長3個月至2026年10月底。勞動部表示，考量國際經貿情勢及產業受到的影響，決定延長措施；10月底後將再觀察減班休息家數、人數、失業率、產業進出率、出口及生產等指標，評估是否繼續辦理。

| 無薪假薪資補貼 | 2026最新規定 |
| --- | --- |
| 正式名稱 | 僱用安定措施 |
| 適用期間 | 延長至2026年10月底 |
| 適用範圍 | 9大公告製造業 |
| 補貼對象 | 符合資格的在職勞工 |
| 補貼比例 | 減班前後薪資差額70% |
| 每月最高補貼 | 11,500元 |
| 公司放無薪假就能領？ | 不一定，仍須符合申請資格 |

「無薪假」是一般常用說法，勞動政策及實務上的正式名稱為減班休息。僱用安定措施補貼的對象是符合資格的勞工，並非直接將補貼發給企業。

## 哪9大行業可以申請？

目前僱用安定措施適用以下9類製造業。判斷重點是受僱事業單位的行業別，不是勞工自己的職稱。

1. 食品及飼品製造業。
2. 紡織業。
3. 橡膠製品製造業。
4. 塑膠製品製造業。
5. 金屬製品製造業。
6. 電力設備及配備製造業。
7. 機械設備製造業。
8. 汽車及其零件製造業。
9. 其他運輸工具及其零件製造業。

例如，在上述製造業公司工作的行政、會計或業務人員，不會只因職稱不是製造人員就被排除；仍應依投保單位行業別及個人其他資格判定。詳細資訊可查看[台灣就業通僱用安定措施專區](https://emps.wda.gov.tw/Internet/Index/labor-reduce.aspx?fm=2)。

## 無薪假補貼可以領多少？

補貼為減班休息前後薪資差額的70%，每人每月最高11,500元。計算時會比較勞工減班休息前的平均月投保薪資與減班後實際協議薪資。

計算方式可簡化為：

**（減班前1至3個月平均月投保薪資－減班後實際協議薪資）×70%**

補貼金額依規定無條件進位至百位數，並受到每月上限限制。

### 無薪假補貼試算

假設減班前1至3個月平均月投保薪資為40,000元，減班後實際協議薪資為30,000元，薪資差額為10,000元；乘以70%後，補貼約為7,000元。

因此，最高11,500元是補貼上限，不是每位實施減班休息的勞工都固定領取。實際金額仍以個人投保薪資、協議薪資及官方核定結果為準。

## 公司放無薪假就能領嗎？

不一定。申請僱用安定措施至少要確認以下條件：

- 受僱事業單位屬公告9大行業。
- 勞雇雙方協議實施減班休息，不能只是雇主單方面宣布。
- 協議書記載的減班休息期間達30日以上。
- 事業單位依法經地方勞工行政主管機關列冊通報。
- 原則上須參加就業保險，實施減班休息前以現職雇主為投保單位參加就保達3個月以上；部分情形另有例外。

全時勞工及有固定工作時數的部分工時勞工都可能適用，但仍須依個別資格判斷。

## 無薪假期間薪水可以低於最低工資嗎？

月薪制全時勞工不可以。2026年最低工資為月薪29,500元、時薪196元，即使勞雇雙方協議減班休息，按月計酬的全時勞工每月工資仍不得低於最低工資。

減班休息必須經勞雇雙方協商同意，雇主不能因訂單減少，就自行宣布減少工作日並降低薪資。政府提供薪資補貼，也不代表雇主原本應負的工資及勞動法令責任可以轉嫁給政府。

## 無薪假薪資補貼怎麼申請？

符合資格的勞工可選擇線上或紙本申請，也可以自行申請或由雇主協助代辦。基本流程為：

**確認公司完成減班休息通報 → 確認個人資格 → 準備申請資料 → 線上或紙本送件 → 勞動力發展署審查 → 核定後撥款**

線上可透過台灣就業通僱用安定措施專區辦理；紙本可向工作所在地的勞動力發展署所屬分署提出。

## 無薪假補貼申請期限多久？

減班休息每滿30日，即可申請一個月薪資補貼。原則上應自每滿30日的次日起90日內提出，因此不能等整段減班休息全部結束後，再無限期回頭申請。

減班期間較長時，可能涉及多期申請，實際仍應依官方核定的期間及申請規定辦理。

## 無薪假補貼要準備哪些資料？

依申請方式與個案不同，文件可能有所差異，常見資料包括：

- 身分證或居留相關身分證明。
- 減班休息期間的薪資證明。
- 本人金融機構存摺影本。
- 僱用安定措施相關申請資料。

由雇主代為辦理時，也應依官方要求準備相應文件。

## 無薪假還能參加再充電計畫嗎？

符合條件者可能可以。勞動部另有「減班休息勞工再充電計畫」，讓勞工利用減少的工作時間參加訓練，符合規定者可取得訓練津貼。

僱用安定措施薪資補貼可在減班休息前後薪資差額範圍內，與符合規定的再充電計畫訓練津貼合併請領。兩項政策並非把最高額度直接相加，仍受薪資差額與各計畫規定限制。

## 公司要求無薪假但沒有通報怎麼辦？

遇到公司要求減班、減薪，可先檢查是否經勞工本人同意、公司有沒有依法通報，以及月薪制全時勞工減班後工資是否仍達最低工資。

若公司實際要求減少工作日、工時或薪資，卻沒有依法協商或通報，可向所在地勞工行政主管機關或勞動部1955勞工諮詢申訴專線確認。至於減班期間兼職是否影響資格，應查看勞動契約與協議約定，並向勞動力發展署確認。

## 常見問題

### 無薪假補貼延長到何時？

目前9大製造業僱用安定措施延長至2026年10月底，之後是否續辦仍待評估。

### 每位勞工都能領11,500元嗎？

不是。11,500元是每月上限，實際補貼依減班前後薪資差額的70%計算。

### 公司實施減班休息就一定能申請嗎？

不一定。仍須符合公告行業、期間達30日、依法通報及就業保險等條件。

### 補貼可以由勞工自己申請嗎？

可以。符合資格者可自行線上或紙本申請，也可由雇主協助代辦。

### 每期補貼何時要提出申請？

原則上減班休息每滿30日的次日起90日內提出申請。
