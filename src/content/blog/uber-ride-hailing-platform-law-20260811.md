Uber、Bolt、yoxi等叫車平台未來可能面臨新的管理規範。立委黃健豪等18人提出《網際網路媒合客運服務管理條例》草案，針對平台法律定位、動態計價、駕駛管理及事故賠償責任等建立新制度，立法院交通委員會8月10日召開立法公聽會。

不過，這項叫車平台專法目前尚未通過，現行Uber等平台的叫車及收費制度也沒有因此立即改變。

## 三大重點先看

- **專法尚未通過**：草案已交付交通委員會審查並舉行公聽會，仍未完成三讀。
- **加強平台責任**：草案擬納管派單、價格、駕駛資格、行程資料及重大事故賠償。
- **車資不會立即改變**：動態計價並未被全面禁止，最終影響仍取決於通過版本。

## Uber專法通過了嗎？目前進度到哪？

還沒有，目前草案已交付交通委員會審查。立法院資料顯示，《網際網路媒合客運服務管理條例》由黃健豪等18名立委提出，7月交付交通委員會，並於8月10日舉行立法公聽會，目前仍屬草案審議階段，尚未完成三讀。

因此，目前沒有已經生效的「Uber專法」或新的Uber收費規定。後續內容仍可能經過修改、協商，甚至改採修正現有法規的方式處理。

## 為什麼要制定叫車平台專法？

現行制度下，依法成立的計程車派遣車隊負責駕駛資格審查、教育訓練、乘客申訴與消費爭議處理；叫車平台可能由車隊自行建立，也可能是車隊與外部資訊平台合作。交通部認為，目前制度並非完全沒有管理機制。

爭議在於，當Uber、Bolt等數位平台實際掌握乘客入口、派單、價格與演算法後，平台究竟只是提供資訊，還是已成為實質派遣者？

2026年1月曾發生乘客透過Bolt搭乘多元計程車，遭駕駛留在台64線快速道路後遭車輛輾斃的案件。事件再次引發平台、合作車隊與駕駛之間如何分配安全管理及賠償責任的討論，也成為立法背景之一。

## Uber專法草案有哪些重點？

草案共16條，核心方向是把對派單及價格具有「實質控制力」的平台獨立納管，而不是只把責任放在傳統計程車車隊。

| 草案重點 | 平台可能新增的責任 |
| --- | --- |
| 平台法律定位 | 將具有派單、價格實質控制力的平台定義為網際網路媒合客運服務業者 |
| 國外平台在地登記 | 國外平台在台營運須辦理分公司登記，並指派代表處理法律及稅務事項 |
| 行程資料保存 | 行車軌跡、派單資料須介接主管機關，至少保存6個月 |
| 駕駛管理 | 審查駕駛資格，辦理交通安全、防酒駕毒駕及服務教育訓練 |
| 車資資訊透明 | 公開計費基準、動態計價演算法原則及平台抽成比例 |
| 動態計價管理 | 費率結構須送主管機關核准，特定情況可暫停動態計價 |
| 事故責任 | 投保責任保險，特定重大事故下可能與駕駛負連帶賠償責任 |
| 產業轉型基金 | 主管機關可按每筆車資總額1%以內徵收數位服務捐 |
| 拒載管理 | 不得因距離、偏遠等不合理因素拒絕或中斷運送 |

其中多項制度與目前規定不同，也是交通部認為草案可能與《公路法》及既有計程車管理制度產生法律競合的原因。

## 動態加價會取消嗎？Uber以後會漲價嗎？

不會因為這份草案就全面取消動態加價。依現行制度，多元化計程車車資本來就須在地方政府公告的運價範圍內計算，平台顯示的計費基準、動態計價及加成費率，也須符合主管機關核准的運價範圍。

交通部指出，目前部分地方政府將多元計程車運價上限定為一般計程車的2倍，也有部分地方政府沒有訂定上限。草案則想增加幾道限制：

- 公開計費基準、動態計價演算法原則與平台抽成比例。
- 動態計價標準及費率結構須送主管機關核准。
- 天災、事變、惡劣天候或特定交通尖峰時，主管機關可暫停動態計價。
- 取消費、違約金或其他服務費也須送主管機關核准。

草案並非禁止加價，而是希望讓加多少、怎麼加、什麼時候不能加受到更直接的監管。

目前也不能認定Uber會因專法而漲價。草案加強費率審查，可能限制部分過高的動態價格；但草案也提出每筆車資總額1%以內的數位服務捐。交通部擔心新增成本可能轉嫁給乘客，實際影響仍要看最終條文。

## 事故發生時平台也要賠嗎？

如果依目前草案版本通過，平台的民事賠償責任會比現行規定明確。草案第10條規定，平台應投保足額的平台責任保險；平台駕駛在服務期間發生重大交通事故或刑事案件時，草案希望將平台視為「實質雇主」，並與駕駛負連帶損害賠償責任。

若駕駛因車輛故障、暴力脅迫或緊急避難等原因必須中斷行程，草案要求駕駛與平台立即通報警方或救援單位，並採取安全安置措施；若未依規定處理而造成損害，也規劃由平台負連帶賠償責任。

民事賠償責任與刑事責任仍須區分。法務部在公聽會書面報告指出，平台若本身沒有刑事違法及可歸責行為，不能只因具有平台業者身分，就替駕駛的犯罪行為承擔刑事責任。

精確來說，草案希望讓平台在特定事故中負民事賠償責任，但不是規定駕駛犯罪後，Uber或Bolt就自動一起負刑事責任。

## 交通部支持另外制定專法嗎？

交通部目前較傾向修改現有法規，而非另訂專法。交通部書面報告指出，草案與依《公路法》建立的計程車客運服務業制度，在定義、營業範圍及管理方式上有不少重疊，可能出現法律競合。

交通部建議維持《公路法》及相關子法的管理架構，再檢討修改《計程車客運服務業申請核准經營辦法》，讓叫車平台的責任與義務更清楚。

換句話說，加強管理平台已有一定共識，但究竟制定專法，還是修改既有計程車法規，仍未定案。

## Uber、Bolt、yoxi怎麼看？

公聽會中，經營yoxi的和泰移動以及Bolt皆表達支持公平監理，並支持進一步確立網路媒合客運服務業者的法律地位。Bolt同時認為，若要增加平台責任，也應釐清平台是否具有雇主身分、現行「一車一隊」制度，以及平台和車隊間的角色分工。

Uber則認為，目前制度已由受監理的車隊透過契約，將部分管理工作委託平台執行，實務上車隊與平台已共同承擔一定責任，因此是否需要另訂專法仍值得討論。

## 常見問題

### Uber專法已經生效了嗎？

尚未。草案仍在立法院交通委員會審查階段，尚未完成三讀。

### Uber動態加價會被取消嗎？

依目前草案不會全面取消，但費率結構須受更直接的審查，特定情況可能暫停動態計價。

### 專法通過後車資一定會上漲嗎？

不一定。費率審查可能抑制部分高價，但數位服務捐等成本是否轉嫁給乘客仍待觀察。

### 發生事故時平台一定要賠嗎？

依目前草案，特定重大事故可能要求平台與駕駛負連帶民事賠償責任，但最終仍以通過條文及個案責任判斷為準。

### 交通部支持這部專法嗎？

交通部支持強化平台管理，但目前較傾向修改《公路法》及既有子法，避免制度重疊。
