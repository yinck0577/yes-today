「可以幫我女兒投一票嗎？」

「朋友的小孩參加繪畫比賽，差幾票就第一名了。」

訊息來自認識多年的LINE好友，照片、名稱看起來都正常，但真正操作這個帳號的人，可能早已換了人。

刑事警察局公布最新統計，2026年8月全台「釣魚連結詐騙」受理505件，較去年同期253件增加99.6%；財損則從1,305萬餘元增加至5,451萬餘元，年增317.7%。近期更出現利用「寵物投票」、「畫作票選」等名義，誘導民眾進入假LINE登入頁，再竊取帳號的案例。

收到LINE好友傳來的投票網址，不代表一定是詐騙；但只要陌生投票網站要求輸入LINE帳密、認證碼，或要求掃描不明QR Code，就應停止操作。若已經輸入資料甚至被登出，處理速度更重要。

## LINE幫忙投票是詐騙嗎？

**不一定，但如果投票到一半突然要求登入LINE、輸入密碼或認證碼，就要提高警覺。**

LINE官方已將「幫忙投票」列為帳號盜用常見手法，包括「幫我的虛擬人偶投個票」、「幫我們家寵物投個票」等訊息，點擊後可能被導向假的LINE登入頁面，要求輸入電話號碼、密碼等帳號資訊。

刑事局2026年9月公布的實際案例中，一名陳姓民眾收到友人傳來「繪畫大公投」網址，對方稱是小孩參加繪畫比賽，希望協助投票。

陳姓民眾點入網站後，依畫面要求輸入LINE帳號、密碼及驗證碼，LINE隨即遭強制登出。之後多名親友陸續收到以他的帳號發送的借款訊息，他才發現帳號已遭盜用。

## 不小心點到LINE投票連結怎麼辦？

先看自己操作到哪一步。

| 目前狀況 | 建議處理 |
|---|---|
| **只有點開網站，沒有輸入資料** | 立即關閉，不要下載檔案、安裝App或繼續操作 |
| **已輸入LINE帳密，但帳號還能用** | 儘快變更密碼、檢查登入裝置及相關安全設定 |
| **已輸入驗證碼，LINE突然被登出** | 不要點選「刪除」，先嘗試「再次登入」 |
| **信用卡資料也已輸入** | 儘快聯絡發卡銀行確認是否需停卡、換卡，並檢查異常交易 |
| **已發生匯款或財損** | 保存對話、網址、交易紀錄等資料，儘速報警 |

如果只有點開連結，沒有輸入帳密、認證碼，也沒有下載檔案、安裝App或授予權限，帳號遭直接接管的風險相對較低，但仍應立即關閉頁面。

也不要把「沒有輸入資料」理解成所有情況都安全。LINE官方提醒，部分惡意連結可能誘導下載不安全的應用程式或檔案，甚至利用假網站進一步操控簡訊功能。

[LINE官方｜如何防止LINE帳號被盜用？](https://help.line.me/line/?contentId=20000293&lang=zh-Hant)

## LINE帳號被盜怎麼辦？還能用、已被登出處理方式不同

**如果LINE還能正常使用，先處理帳號安全設定。**

LINE官方建議，可先變更密碼、關閉「允許自其他裝置登入」，再查看目前登入中的裝置，將不認識或可疑的裝置登出。

若使用與其他網站相同的密碼，也建議一併變更，避免同一組帳密被拿去嘗試登入其他服務。

### LINE突然顯示「已登出帳號」怎麼辦？

**先不要按「刪除」。**

如果是在點擊可疑連結、輸入帳密或驗證碼後，LINE突然出現「已登出帳號」畫面，LINE官方建議先依畫面嘗試「再次登入」，仍有機會找回帳號。

LINE也特別提醒，如果在「已登出帳號」的再次登入頁面點選「刪除」，儲存在該裝置內的LINE相關資料可能被刪除。

如果無法再次登入，可透過LINE官方「與我們聯絡」表單提出帳號遭盜諮詢，由本人提供帳號資訊及發生經過供客服確認。

## LINE驗證碼輸入釣魚網站會怎樣？

**可能讓詐騙者完成LINE帳號認證或登入程序，進一步取得帳號控制權。**

LINE官方說明，除了使用者本人主動進行移動LINE帳號等操作外，平常使用LINE並不需要把認證碼提供給其他人。若有人索取LINE帳號資訊、認證碼，或要求協助輸入認證碼，都應提高警覺。

因此，如果「投票網站」突然跳出LINE登入畫面，又要求輸入手機收到的認證碼，不要因為驗證碼只有幾位數就照著填。

同樣原則也適用於銀行OTP、信用卡驗證碼等資料。

## 為什麼LINE好友傳來的訊息也可能是詐騙？

因為帳號是真的，操作帳號的人卻可能已經不是本人。

這類盜號手法可能一路延伸：

**A的LINE遭盜用 → 詐騙者冒充A找B投票 → B進入假網站輸入帳密、認證碼 → B的LINE也遭盜用 → 再用B的帳號找C、D、E。**

刑事局指出，詐騙集團取得LINE帳號後，可能冒用帳號原本的身分，向好友借款或繼續散布惡意連結。

因此，訊息從熟悉的LINE帳號送來，只能證明「這個帳號傳了訊息」，不能單靠帳號名稱與大頭貼確認正在操作的人就是本人。

遇到投票、借款、轉帳等要求，可以直接改用電話、當面或其他已知聯絡方式確認。

## 哪些LINE投票最容易是釣魚連結？

近期警方及LINE官方示警的話術包括：

- 幫小孩參加繪畫比賽投票
- 寵物比賽投票
- 虛擬人偶人氣票選
- 幫忙按讚
- 抽獎活動
- 投票前要求LINE登入
- 要求輸入帳號、密碼或認證碼
- 要求掃描不明QR Code

真正需要注意的不是「投票」兩個字，而是**操作過程是否突然索取原本不需要提供的帳號資訊。**

尤其當網頁要求輸入LINE帳密及認證碼時，就不應繼續操作。

## LINE怎麼防止釣魚連結？可以開啟「偵測可疑網站」

LINE本身已有釣魚網站偵測功能。

手機主要裝置可依序進入：

**LINE主頁 → 設定 → 聊天 → 開啟「偵測可疑網站」**

開啟後，系統可偵測聊天室收到的連結是否屬於釣魚網站，使用者嘗試開啟被判定為可疑的連結時，LINE會顯示警告訊息。這項功能須同時開啟網址預覽才能使用。

Windows、Mac版則可進入：

**設定 → 聊天 → 基本 → 開啟「偵測並標示曾被檢舉的可疑網站」**

不過，系統沒有跳出警告，不代表網址就一定安全。收到陌生連結時，仍應自行確認網址及訊息來源。

[LINE官方｜偵測聊天室內收到的釣魚網站](https://help.line.me/line/smartphone/sp?contentId=200001870&lang=zh-Hant)

## 釣魚連結詐騙真的變多了嗎？8月505件、財損5451萬元

**是，而且財損增加幅度比案件數更明顯。**

根據165打詐儀錶板統計，2026年8月全台電信網路詐騙受理1萬652件，總財損約41億757萬元。與2025年同期相比，整體案件數下降22.3%，總財損也下降35.1%。

但其中「釣魚連結詐騙」卻逆勢增加：

| 釣魚連結詐騙 | 2025年8月 | 2026年8月 | 年增幅 |
|---|---:|---:|---:|
| 受理件數 | 253件 | **505件** | **＋99.6%** |
| 財損 | 約1,305萬元 | **約5,451萬元** | **＋317.7%** |

換句話說，2026年8月整體電信網路詐騙案件與財損較去年同期下降，但釣魚連結案件數接近翻倍，財損更增至去年同期約4.18倍。

[刑事警察局｜慎防釣魚連結及LINE帳號被盜用來詐騙](https://www.cib.npa.gov.tw/ch/app/news/view?id=1885&module=news&serno=dc96426e-60ee-4b56-8fc2-a8c1f8aabf1d)

## 不只LINE投票！停車費、電信點數也是近期釣魚話術

釣魚連結並不限於LINE。

刑事局指出，近期詐騙集團還會假冒政府機關、電信業者、金融服務、電商及物流公司，以日常生活中容易讓人急著處理的通知誘導點擊。

| 假冒類型 | 常見話術 |
|---|---|
| **電信業者** | 點數即將到期、電信費欠繳 |
| **ETC、eTag** | 通行費未繳、扣款失敗 |
| **停車通知** | 停車費尚未繳納 |
| **政府機關** | 退稅、發票中獎、罰單未繳 |
| **金融服務** | 付款失敗、交易異常、帳戶驗證 |
| **電商平台** | 訂單異常、退款、重複訂購 |
| **物流業者** | 配送失敗、訂單異常 |
| **LINE好友** | 投票、抽獎、借錢 |

其中假冒電信及交通收費通知，是刑事局近期特別點出的常見類型。

詐騙網站可能要求輸入信用卡資料，也可能把民眾導向LINE「線上客服」，再以取消重複扣款、帳戶認證等理由，要求操作網路銀行、ATM或掃描QR Code。

## LINE帳號被盜後，朋友也可能收到借錢訊息嗎？

**會。**

刑事局公布的案例顯示，詐騙者取得LINE帳號控制權後，可能直接冒用原帳號持有人身分，向好友傳送借款訊息。

這類訊息可能寫成：

「臨時急用，可以先借我2萬元嗎？」

「今天轉帳額度滿了，可以先幫我匯嗎？」

「現在不方便講電話，晚點再跟你說。」

除了親友，企業也可能成為目標。刑事局近期另揭露冒充公司主管要求員工匯款的案件，因此只要訊息突然涉及借錢、匯款或提供金融資訊，都應另外確認本人身分。

## 收到好友投票連結怎麼判斷？5件事先確認

收到LINE好友傳來投票、抽獎或按讚網址時，可以先檢查：

1. **是不是突然收到過去很少出現的投票或抽獎要求**
2. **網址是否陌生，或刻意模仿知名網站**
3. **點入後是否突然要求登入LINE**
4. **是否要求輸入帳號、密碼、認證碼或掃描QR Code**
5. **改用電話、當面或其他已知聯絡方式，確認本人是否真的傳過這個連結**

其中，只要陌生網頁要求輸入LINE帳密及認證碼，就不要繼續操作。

收到好友傳來的投票連結，可以先確認本人；一旦網頁要求輸入LINE帳密、認證碼或掃描不明QR Code，就停止操作。若已經被登出，先不要點選「刪除」，立即依LINE官方流程嘗試再次登入。
