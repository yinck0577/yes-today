*主圖為情境示意圖，非廣慈／奉天宮站實際站景。*

台北捷運淡水信義線再往東延伸！**廣慈／奉天宮站已於2026年8月30日下午2時正式加入營運**，淡水信義線東端終點從原本的象山站延伸至R01廣慈／奉天宮站。新站通車後，台北捷運營運車站增加至118站，路網長度也從131.1公里增加至132.5公里。

配合通車，北捷自**8月30日至9月28日**推出首月乘車優惠，只要進站或出站其中一端為廣慈／奉天宮站，新通車的象山至廣慈／奉天宮區間不計票價；9月29日起則恢復一般票價計算。淡水信義線也同步啟用新的營運模式，全程車可從淡水一班車直達廣慈／奉天宮，單向全程約61分鐘。

[台北捷運｜廣慈／奉天宮站通車官方公告](https://www.metro.taipei/News_Content.aspx?n=30CCEFD2A45592BF&s=CB42925269CE131D&sms=72544237BBE4C5F6)

## 廣慈／奉天宮站在哪裡？是捷運哪一條線？

廣慈／奉天宮站屬於台北捷運**淡水信義線，也就是俗稱的紅線，車站編號為R01**，目前是淡水信義線最東端終點站。

信義線東延段從原本象山站向東延伸，沿信義路六段抵達廣慈博愛園區，新通車路段約1.4公里。廣慈／奉天宮站加入後，台北捷運路網總長度增加至132.5公里。

淡水信義線東側目前的車站順序為：

**淡水方向 ← 台北101／世貿R03 ← 象山R02 ← 廣慈／奉天宮R01**

也就是說，過去搭紅線到象山就必須下車，現在可以繼續往前搭一站到廣慈／奉天宮。

| 廣慈／奉天宮站 | 通車資訊 |
|---|---|
| 捷運路線 | 淡水信義線（紅線） |
| 車站編號 | R01 |
| 正式通車 | **2026年8月30日** |
| 前一站 | 象山R02 |
| 新增路段 | 約1.4公里 |
| 首月優惠 | **新通車區間不計票價** |
| 優惠期間 | **8/30～9/28** |
| 淡水到新站 | **全程約61分鐘** |
| 北捷營運車站 | **118站** |
| 北捷營運里程 | **132.5公里** |

## 廣慈／奉天宮站免費到什麼時候？8/30至9/28新路段不計票價

廣慈／奉天宮站通車後，北捷推出一個月的乘車優惠，期間為**2026年8月30日至9月28日**。

優惠方式不是整趟捷運免費，而是：

> **象山站至廣慈／奉天宮站的新通車區間不計票價，其餘搭乘里程仍正常收費。**

不過，這項規則還有一個容易忽略的條件：**進站或出站其中一端必須是廣慈／奉天宮站，才能適用新通車區間不計票價的優惠。**

如果旅客的進站、出站都不是廣慈／奉天宮站，即使搭乘淡水信義線，也不會額外獲得這項通車優惠。

因此可以簡單理解成：

**「搭到或從廣慈／奉天宮出發，首月不計象山到新站這一段的票價。」**

並不是「紅線8月30日後全部少收一站」。

## 象山到廣慈／奉天宮真的0元嗎？

**8月30日至9月28日期間，單純往返象山與廣慈／奉天宮，新通車區間本身就是0元。**

如果使用悠遊卡、一卡通、愛金卡、QR乘車碼或信用卡等電子支付方式，可以直接依北捷票證系統進出站。

但如果沒有使用上述電子票證，只想搭乘象山至廣慈／奉天宮，或在廣慈／奉天宮站同站進出，北捷另外設有乘車處理方式，旅客須向車站詢問處洽詢並索取乘車憑證，而不是到售票機購買一張「0元單程票」。

所以如果只是想趁通車首月去新站看看，最簡單的方式還是使用一般電子票證進出站。

## 廣慈／奉天宮站票價多少？9/29起恢復正常計費

8月30日至9月28日為通車優惠期，9月29日起新通車區間恢復一般里程計費。優惠期間，象山與廣慈／奉天宮之間不計票價；其他車站往返廣慈／奉天宮，則先扣除新通車區間里程，再依現行票價計算。

北捷公告指出，車站票價表以粉紅色底標示優惠期間與正式收費不同的票價；沒有粉紅色底的金額，優惠結束後也不會改變。

特定起訖站的實際票價，請使用北捷官方查詢，不自行以公里數換算。

## 廣慈／奉天宮怎麼搭？淡水可以一班車直達

廣慈／奉天宮站加入後，淡水信義線的全程車營運模式正式改成：

**淡水－廣慈／奉天宮**

因此從淡水、北投、士林、中山、台北車站、大安、台北101／世貿或象山等紅線車站出發，只要搭乘目的地顯示「廣慈／奉天宮」的全程車，就能一班車抵達新站，**不需要在象山換車**。

目前淡水信義線主要營運模式包括：

- 全程車：**淡水－廣慈／奉天宮**
- 區間車：**北投－大安**
- 尖峰部分區間車：**北投－廣慈／奉天宮**

因此，搭乘紅線時還是要注意月台資訊顯示的終點站。

如果列車目的地是：

> **廣慈／奉天宮**

就可以直接坐到R01。

### 淡水到廣慈／奉天宮要多久？

北捷最新營運資料顯示，**淡水至廣慈／奉天宮全程單向約61分鐘**。

也就是說，從紅線最北端一路坐到目前最東端，約一小時左右可以完成，而且不用換車。

## 廣慈／奉天宮班距多久？平日尖峰約3分鐘一班

新站通車後，淡水信義線平日尖峰的全程車及區間車平均班距約6分鐘。

不過，由於尖峰時段部分北投區間車會延駛至廣慈／奉天宮，因此**北投至廣慈／奉天宮區間平均約3分鐘就有一班車**。

北捷目前公布的主要班距如下：

| 時段 | 淡水信義線班距 |
|---|---|
| 平日尖峰 | 全程車／區間車約6分鐘 |
| 平日尖峰北投－廣慈／奉天宮 | **約3分鐘** |
| 平日離峰 | 約8～9分鐘 |
| 平日離峰北投－大安重疊區間 | 約4～4.5分鐘 |
| 假日08:00～23:00 | 約7～10分鐘 |
| 假日北投－大安重疊區間 | 約3.5～5分鐘 |
| 23:00後 | 約12分鐘 |

上表離峰及假日的較短班距適用於北投－大安重疊區間，不代表廣慈／奉天宮站全天都有相同班距。實際班次仍可能因人潮、設備狀況或特殊活動調整。

其中變化最直接的是淡水信義線，因東端終點從象山延伸到廣慈／奉天宮，部分全程車、區間車及首末班車時間也跟著調整。北捷目前已在新版路網與各站頁面提供最新時刻表查詢。

## 廣慈／奉天宮站可以帶自行車、寵物車嗎？9/29才開放

**8月30日至9月28日通車優惠期間，廣慈／奉天宮站暫停開放部分大型物品進出。**

北捷公告包括：

- 自行車
- 大型寵物車
- 低音提琴

上述物品預計從**9月29日起**才正式開放進、出廣慈／奉天宮站。北捷表示，主要是考量首月可能有大量民眾前往新站體驗，為維持站內動線與旅客安全而採取的暫時措施。

因此，如果9月28日前打算騎自行車搭捷運前往新站，或攜帶大型寵物車，需特別留意。

## 廣慈／奉天宮站首月還有哪些通車活動？

除了首月票價優惠，北捷也推出「奉天乘運 廣慈迎賓」系列活動，包括迎賓音樂會、市集及抽獎等。

活動獎項曾公布雙人來回機票、捷運年票、自行車與霜淇淋等，但各項活動時間不同，有些只限通車首日或9月初特定日期，因此如果是為了活動前往，不建議只看文章日期判斷是否仍有效。

## 象山站還是淡水信義線終點嗎？

**不是。**

自8月30日起，淡水信義線東端終點已正式從**象山R02**延伸至**廣慈／奉天宮R01**。

因此現在看到新版捷運路網圖，紅線最東端已經不是象山，而是廣慈／奉天宮。

象山仍然是正常營運車站，只是不再扮演整條淡水信義線的東端終點。

## 廣慈／奉天宮通車後，紅線成為北捷最長路線

廣慈／奉天宮站加入後，也讓淡水信義線拿下一個新的北捷紀錄。

依台北捷運8月30日更新的官方路網資料，淡水信義線目前從**淡水站一路到廣慈／奉天宮站，若包含新北投支線，全長30.7公里，共29個車站**。

拿目前北捷5條主要路線比較：

| 路線 | 官方路線長度 |
|---|---:|
| 淡水信義線 | **30.7公里** |
| 中和新蘆線 | 29.4公里 |
| 板南線 | 26.5公里 |
| 文湖線 | 25.2公里 |
| 松山新店線 | 20.7公里 |

因此，以北捷官方目前公布的路線長度來看，**淡水信義線已是台北捷運公司營運的5條路線中最長的一條。**

從淡水坐到廣慈／奉天宮約61分鐘，也成了紅線很直觀的「從河岸一路坐進信義區東端」體驗。

## 台北第一條捷運是哪一條？不是淡水線

廣慈／奉天宮站通車時，台北捷運其實剛好也走到第30年。

台北捷運第一條正式營運的路線，是現在文湖線前身的**木柵線**。

木柵線於**1996年3月28日**正式通車，當時全長10.5公里，也是全台第一條無人駕駛中運量捷運系統。之後才在1997年3月28日迎來淡水線「淡水－中山」段，成為全台第一條高運量捷運系統。

所以如果問：

> 台灣第一條捷運是哪條？

答案是**木柵線**。

如果問：

> 台灣第一條高運量捷運是哪條？

答案才是**淡水線**。

從1996年第一條木柵線10.5公里，到2026年廣慈／奉天宮加入後的132.5營運公里，台北捷運用了30年時間，從一條線逐漸長成現在的都會路網。

## 廣慈／奉天宮站通車懶人包：搭車先看7個重點

廣慈／奉天宮站已正式營運，近期要搭車可以先記住幾件事：

1. **廣慈／奉天宮是淡水信義線新的R01終點站。**
2. **8月30日至9月28日新通車區間不計票價。**
3. 優惠原則上要有一端從**廣慈／奉天宮進站或出站**。
4. **象山至廣慈／奉天宮首月0元**，無電子票證者需依車站規定索取乘車憑證。
5. 淡水可搭全程車直接到廣慈／奉天宮，**單向約61分鐘**。
6. 平日尖峰北投至廣慈／奉天宮區間平均約**3分鐘一班**。
7. 自行車、大型寵物車及低音提琴要到**9月29日**才開放從新站進出。

對一般旅客而言，新站通車最直接的改變，是象山不再是紅線終點；對信義區東側與廣慈博愛園區周邊居民來說，則等於正式接入台北捷運主幹路網。

而從整個台北捷運發展來看，廣慈／奉天宮這短短1.4公里，也讓營運30年的台北捷運來到**118站、132.5公里**，並讓淡水信義線以30.7公里成為目前北捷5條主要路線中最長的一條。
