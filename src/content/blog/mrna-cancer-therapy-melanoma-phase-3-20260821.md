mRNA技術往癌症治療再跨一步。Moderna與Merck（默沙東）8月19日宣布，旗下個人化mRNA癌症療法intismeran autogene（mRNA-4157／V940）搭配免疫治療藥物KEYTRUDA（pembrolizumab），在高風險黑色素瘤第三期INTerpath-001試驗中達標。

試驗的主要療效指標無復發存活期（RFS），以及關鍵次要療效指標無遠端轉移存活期（DMFS），都取得統計顯著且具臨床意義的改善。Moderna表示，這是首個在隨機第三期癌症試驗取得正面結果的mRNA癌症療法里程碑。

不過，這項成果目前仍是研究中的個人化癌症治療。它不是健康民眾用來預防癌症的疫苗，也尚未獲准上市；第三期完整療效幅度與詳細安全性數據，目前也尚未正式公布。

## 三大重點先看

- **第三期試驗達標：**合併療法在RFS與DMFS均優於KEYTRUDA加安慰劑的對照組。
- **不是預防癌症的疫苗：**療法依患者腫瘤突變量身製作，用於已接受完整手術切除的高風險黑色素瘤患者，目標是降低復發或轉移風險。
- **尚未上市：**完整第三期數據仍待醫學會議發表與監管機關審查，台灣目前不能常規使用。

## mRNA癌症疫苗成功了嗎？第三期試驗達標

可以說第三期試驗成功達標，但不能說「癌症疫苗已研發成功並上市」。

INTerpath-001納入第IIB至IV期、已接受完整手術切除的高風險黑色素瘤患者，比較intismeran autogene加KEYTRUDA，與KEYTRUDA加安慰劑的療效。研究結果顯示，合併療法在RFS與DMFS兩項療效指標均優於對照組。

| 「成功」指什麼？ | 現在狀態 |
| --- | --- |
| 第三期主要療效指標RFS達標 | 是 |
| 關鍵次要療效指標DMFS達標 | 是 |
| 完整第三期數據已公布 | 否 |
| 已獲FDA核准 | 否 |
| 已正式上市 | 否 |
| 台灣現在可以施打 | 否 |
| 已證明能治癒癌症 | 否 |

這項研究屬於術後輔助治療（adjuvant therapy）。也就是患者的黑色素瘤已完整切除，再透過後續治療降低復發或遠端轉移風險，而不是用mRNA療法直接消除仍存在的大型腫瘤。

## 第三期效果多好？完整數字尚未公布

目前還不知道第三期究竟降低多少比例的復發或轉移風險。

8月19日公布的是第三期主要結果摘要。Merck與Moderna確認RFS與DMFS均取得統計顯著且具臨床意義的改善，但尚未公布完整風險比、絕對差異及完整安全性資料。兩家公司表示，詳細結果將在後續醫學會議發表，並提交主管機關討論。

因此，現階段不能把「降低復發風險49％」寫成第三期結果，因為49％來自較早的第二期試驗。

## 二期追蹤5年：復發或死亡風險降低49％

較早的第二期KEYNOTE-942研究可作為參考。Merck與Moderna今年6月公布五年追蹤結果，intismeran autogene加KEYTRUDA相較KEYTRUDA單獨治療：

- 復發或死亡風險降低49％，HR 0.51。
- 遠端轉移或死亡風險降低59％，HR 0.411。

49％與59％都是第二期五年追蹤資料，不是8月19日公布的第三期療效幅度。這些數字能說明第三期為何受到高度關注，但不能直接代表第三期效果。

## mRNA癌症疫苗是什麼？和新冠疫苗一樣嗎？

兩者都利用mRNA傳遞製造抗原的指令，但抗原來源、治療目的與製作方式不同。

Intismeran autogene屬於個人化新抗原療法（individualized neoantigen therapy），會根據每位患者腫瘤DNA的獨特突變設計，可編碼最多34個腫瘤新抗原。

製作流程可簡化為：

**取得患者腫瘤與正常組織 → 分析腫瘤突變 → 挑選最多34個新抗原 → 製作個人化mRNA療法 → 注射後讓細胞呈現抗原 → 啟動針對癌細胞的T細胞免疫反應**

因此，每位患者接受的intismeran autogene內容可能不同。

| 比較 | mRNA新冠疫苗 | intismeran autogene |
| --- | --- | --- |
| 目的 | 預防感染或重症 | 降低癌症復發、轉移 |
| 對象 | 一般符合接種資格者 | 已罹癌的特定患者 |
| 抗原來源 | 病毒抗原 | 患者腫瘤新抗原 |
| 每個人配方 | 原則相同 | 個人化設計 |
| 定位 | 預防性疫苗 | 治療性癌症療法 |

媒體俗稱「mRNA癌症疫苗」方便理解，但更精確的名稱是個人化mRNA癌症療法。

## 可以讓健康民眾預防癌症嗎？

目前這款療法不能給健康民眾預防癌症。

INTerpath-001的患者都已罹患黑色素瘤並完成手術，後續使用intismeran autogene加KEYTRUDA，是為降低癌症再次出現或遠端轉移的風險。

這和HPV疫苗、B型肝炎疫苗不同。後兩者透過預防病毒感染，進一步降低相關癌症風險；intismeran autogene則是在癌症發生後，依患者腫瘤突變打造治療。

## 為什麼要搭配KEYTRUDA？

這次第三期證明的是intismeran autogene加KEYTRUDA的組合療法優於KEYTRUDA加安慰劑，不是證明mRNA療法單獨使用也有相同效果。

可以把兩種治療理解成不同任務：intismeran autogene負責讓免疫系統更容易認出癌細胞；KEYTRUDA則解除癌細胞對免疫反應的「煞車」。

KEYTRUDA是PD-1免疫檢查點抑制劑，可解除部分腫瘤對T細胞反應的抑制；個人化mRNA療法則希望建立更具腫瘤特異性的T細胞反應。因此，這次結果真正證實的是兩種免疫策略的組合治療在第三期達標。

## 有哪些副作用？

第三期目前僅公布整體安全性與既有研究一致，未發現新的重大安全訊號，詳細安全性數據仍待後續公布。

第二期五年追蹤則提供較具體的參考資料。以下比例是第二期資料，不是第三期完整結果：

| intismeran相關常見不良事件 | 發生比例 |
| --- | --- |
| 疲倦 | 59.6％ |
| 注射部位疼痛 | 59.6％ |
| 畏寒 | 51.0％ |

多數intismeran相關不良事件為Grade 1或Grade 2；最常見的Grade 3事件為疲倦，占4.8％，研究中沒有出現Grade 4至5的intismeran相關不良事件。

免疫相關不良事件在合併組為45.2％，KEYTRUDA單獨組為44％。第二期資料未顯示加入intismeran後明顯增加這類免疫相關副作用。

## 何時上市？台灣現在可以用嗎？

目前還不行。Intismeran autogene仍是研究中療法，尚未取得美國FDA正式上市核准，也不是台灣目前可常規使用的癌症治療。

Merck與Moderna表示，將向全球監管機構提交第三期資料並討論後續申請。目前仍待確認的問題包括：

- 何時正式提交藥證申請。
- FDA何時完成審查。
- 最終適應症涵蓋哪些黑色素瘤患者。
- 台灣何時提出藥證申請。
- 未來定價與是否可能納入健保。

第三期達標是重要一步，但從「試驗成功」到「患者實際能用」，仍需完整數據發表、監管審查及藥證程序。

## 還能治哪些癌症？肺癌也進入三期

黑色素瘤是目前進展最快的癌別，但Moderna與Merck已把intismeran autogene擴展到其他腫瘤。截至2026年6月，兩家公司共有9項第二、三期臨床試驗研究intismeran autogene加KEYTRUDA，涵蓋：

- 黑色素瘤。
- 非小細胞肺癌（NSCLC）。
- 膀胱癌。
- 腎細胞癌。

其中非小細胞肺癌已有第三期研究。接下來真正要觀察的，是個人化mRNA療法能否在其他腫瘤複製療效，以及高度客製化的製造流程能否走進日常臨床。
