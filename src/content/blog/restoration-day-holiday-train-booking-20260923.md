2026光復節連假準備搭雙鐵返鄉、出遊，先記住兩個主要搶票時間：**台鐵9月23日已開賣，高鐵9月25日凌晨0時開賣**。今年光復節10月25日適逢星期日，10月26日星期一補假，10月24日至26日共放3天；台鐵9月24日另有4列連假加班實名制列車開放訂票，9月25日上午9時還會重新釋出首波逾期未取票。

台鐵截至9月23日上午9時，共完成4萬3,700筆、7萬2,366張訂票，**台鐵當時表示各時段仍有餘位**。不過餘票會隨訂位、付款及退換票持續變動，實際座位仍應以即時訂票系統為準。

## 2026光復節連假放哪幾天？10/24至10/26連休3天

**2026光復節連假從10月24日星期六放到10月26日星期一，共3天。**

今年「臺灣光復暨金門古寧頭大捷紀念日」10月25日落在星期日，因此於下一個上班日10月26日補假。

| 日期 | 星期 | 放假安排 |
|---|---|---|
| **10/24** | 六 | 週休 |
| **10/25** | 日 | 臺灣光復暨金門古寧頭大捷紀念日 |
| **10/26** | 一 | **補假** |
| **10/27** | 二 | 恢復上班 |

實際連假雖然只有3天，但高鐵與台鐵都把前後旅運尖峰納入疏運，因此疏運期均從**10月23日至27日**。

## 2026光復節高鐵、台鐵何時搶票？5個時間一次看

今年雙鐵開賣時間不同，台鐵另外還有兩種容易搞混的實名制。準備訂票可先記住以下5個時間：

| 時間 | 搶票、交通重點 |
|---|---|
| **9/23 00:00** | 台鐵一般訂票開放；花東地區實名制同步開放符合資格旅客優先訂票 |
| **9/24 00:00** | 台鐵4列「連假加班實名制」開放符合資格旅客訂票 |
| **9/25 00:00** | **高鐵光復節疏運車票開賣** |
| **9/25 09:00** | 台鐵9/23首波逾期未取車票重新釋出 |
| **9/26 00:00** | 花東地區實名制剩餘座位全面開放一般旅客訂票 |

其中最容易混淆的是9月23日與24日：**9月23日開放的是一般訂票與「花東地區實名制」；9月24日開放的則是光復節另外加開4列的「連假加班實名制」。**

## 2026光復節高鐵票何時開賣？9/25凌晨0時

**光復節高鐵車票將於9月25日凌晨0時開賣。**

台灣高鐵規劃10月23日至27日共5天光復節疏運，期間加開**86班次**，南下、北上各43班，5天總計提供**905班次**旅運服務。

| 高鐵光復節疏運 | 時間／班次 |
|---|---|
| **連假日期** | 10/24～10/26 |
| **高鐵疏運期間** | 10/23～10/27 |
| **開放購票** | **9/25凌晨0時** |
| **加開班次** | 86班 |
| **南下加班車** | 43班 |
| **北上加班車** | 43班 |
| **5天總班次** | 905班 |

高鐵官方2026年疏運日程表也已將光復節列為10月23日至27日疏運，開放預售日期為9月25日；最新光復節疏運時刻表也已上線。

旅客可透過網路訂票、高鐵合作便利商店及T-EX行動購票App購票，也能在營業時間內使用車站售票窗口及自動售票機。

### 光復節高鐵還有早鳥、大學生優惠嗎？

**有。**

光復節疏運期間仍維持「早鳥優惠」、「大學生優惠」及「商務車廂限量升等」等專案；但「TGo會員月月Go有禮」、「指定車次團體」、「校外教學團體」及「指定區間團體」等專案不適用。

早鳥優惠採限量方式提供，因此能否買到折扣票，仍要以實際訂票系統顯示為準。

### 光復節高鐵自由座有幾節？各車次2至9節

**光復節疏運期間，高鐵各車次配置2至9節不等的自由座車廂。**

實際自由座節數依車次不同，並非每班都有9節。高鐵也會針對台中以北自由座需求較高的時段擴大運能。

自由座旅客到站後，可透過站內「旅客資訊顯示系統」確認該班列車的自由座配置；高鐵網站、T-EX App及LINE TODAY生活頻道也會提供「自由座等候時間」預估燈號，可在搭車前先確認尖峰狀況。

### 10/25、10/26高鐵1336車次凌晨才到南港　自由座只有2節

搭乘特定深夜班次還要注意一項例外。

**10月25日及26日北上1336車次，只提供第11、12車作為自由座，也就是只有2節自由座車廂。**

而且這兩天1336車次抵達終點南港站時已超過凌晨0時。如果準備搭乘這班車返回雙北，除了要留意自由座數量，也應先確認抵達南港後的捷運、公車或其他接駁方式。

## 2026光復節台鐵票開賣了嗎？9/23已開放訂票

**已經開賣。**

台鐵自9月23日凌晨0時起開放光復節一般車票預訂，10月23日至27日5天疏運期間，全線共加開**108列次**，其中西線37列次、東線71列次。

| 台鐵光復節疏運 | 規劃 |
|---|---|
| **疏運期間** | 10/23～10/27 |
| **一般訂票** | 9/23凌晨0時起 |
| **加開列次** | **108列次** |
| **西線** | 37列次 |
| **東線** | 71列次 |
| **9/23上午9時訂票量** | 7萬2,366張 |
| **9/23上午9時狀態** | 台鐵公告當時各時段仍有餘位 |

截至9月23日上午9時，台鐵共完成4萬3,700筆、7萬2,366張訂票，當時公告各時段仍有餘位。

不過這是**9月23日上午9時的時間截點**，不代表之後所有班次仍有座位。現在仍可直接查詢欲搭乘班次，實際餘票以台鐵即時訂票系統為準。

## 台鐵沒搶到票怎麼辦？9/25上午9時首波逾期票重新釋出

如果熱門時段暫時沒有理想座位，可以再記一個時間：

> **9月25日上午9時。**

台鐵規定，9月23日完成訂票的旅客，應於**2日內，包含訂票當日**完成取票或付款；首波逾期未取車票將在9月25日上午9時重新釋出。

不過重新釋出的張數會受到付款、取消、退票及換票情況影響，因此不能保證特定車次一定會重新出現座位。

另外，台鐵目前規定，旅客若在**1個月內累積6次訂票未付款紀錄，將停權1個月**，訂位後若確定不搭乘，應在期限內取消。

## 光復節台鐵加班實名制何時訂？9/24凌晨0時

**光復節4列「連假加班實名制」於9月24日凌晨0時開放符合資格旅客訂票。**

這4班分別安排在10月23日、24日及26日，包含2班返鄉、2班返工列車：

| 日期 | 車次 | 區間 |
|---|---:|---|
| **10/23** | 5252次 EMU3000 | 樹林→臺東 |
| **10/24** | 5208次 太魯閣 | 樹林→花蓮 |
| **10/26** | 5215次 EMU3000 | 花蓮→樹林 |
| **10/26** | 5241次 EMU3000 | 臺東→樹林 |

符合資格者包括**設籍花蓮縣、臺東縣者，國民身分證統一編號第1碼為U或V者，以及上述兩類對象的配偶與直系血親1親等國民**。

連假加班實名制若仍有剩餘座位，台鐵規定將於**乘車日前2日起開放所有旅客無記名購票**。

### 花東地區實名制也是9/24嗎？

**不是。**

「花東地區實名制」和前面的「連假加班實名制」是兩種不同訂票管道，也是今年光復節訂票最容易搞混的地方。

| 實名制類型 | 開放時間 | 重點 |
|---|---|---|
| **花東地區實名制** | **9/23凌晨0時** | 符合資格旅客優先訂票 |
| **花東地區實名制剩餘座位** | **9/26凌晨0時** | 全面開放一般旅客訂票 |
| **連假加班實名制** | **9/24凌晨0時** | 針對10/23、10/24、10/26加開的4列實名制列車 |

2026光復節期間，花東地區實名制可預訂的乘車日期為**10月21日至27日**；符合資格旅客9月23日凌晨0時起可優先預訂，9月26日凌晨0時起，剩餘座位再全面開放一般旅客。

因此看到「9月24日實名制開賣」時，指的是**連假加班實名制**，不能直接寫成「花東實名制9月24日開賣」。

## 光復節台鐵EMU3000有自由座嗎？西部幹線改售200張無座票

**光復節疏運期間，西部幹線EMU3000暫停自由座服務。**

10月23日至27日，台鐵改成於**乘車當日限量發售200張無座票**，持無座票旅客不得進入第6車騰雲座艙。

這裡要特別區分：

> **自由座 ≠ 無座票。**

這5天不是照平常方式保留EMU3000自由座車廂，而是改成限量販售無座票。

旅客可透過台鐵官網訂票，再至車站窗口、自動售票機取票，或使用「台鐵e訂通」App取票。

## 台鐵親子車廂光復節還能訂嗎？

**10月23日至27日光復節疏運期間，台鐵暫停發售親子車廂車票，原親子車廂改以一般車廂方式售票。**

如果原本計畫在光復節連假購買親子車廂，這5天要特別注意。

## 2026光復節雙鐵訂票重點一次看

準備搭雙鐵返鄉或出遊，最後掌握5個重點：

1. **高鐵9/25凌晨0時開賣**，疏運5天加開86班、總計905班。
2. **台鐵9/23已開賣**，光復節疏運共加開108列次。
3. **台鐵連假加班實名制9/24凌晨0時開賣**，共4列，和花東地區實名制不同。
4. **台鐵首波逾期未取票9/25上午9時重新釋出**，沒搶到票可再查一次。
5. **西部EMU3000光復節期間暫停自由座**，改成乘車當日限量販售200張無座票。

另外，花東地區實名制已於9月23日開放符合資格旅客優先訂票，**9月26日凌晨0時起剩餘座位將全面開放一般旅客**。如果9月23日一般訂票沒有找到適合的東部座位，9月25日逾期票重新釋出及9月26日花東實名制剩餘座位開放，都是接下來可以留意的時間點。
