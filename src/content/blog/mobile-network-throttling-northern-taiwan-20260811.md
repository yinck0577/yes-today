2026城鎮韌性（防空）演習將於8月13日下午2時30分至3時在北部登場，台北、新北、基隆、桃園、新竹縣、新竹市及宜蘭共7縣市，同步實施30分鐘「行動網路降速演練」。

這次並非完全斷網，語音通話、簡訊、110、119等基本通訊仍維持運作，但影音串流、視訊通話、行動支付、雲端同步等需要較多行動數據的服務可能受到影響。8月10日中部首波實測時，也已有民眾反映網頁、LINE圖片與行動支付App明顯卡頓。

## 三大重點先看

- **演練時間**：2026年8月13日下午2時30分至3時，共30分鐘。
- **影響範圍**：台北、新北、基隆、桃園、新竹縣、新竹市及宜蘭。
- **不是完全斷網**：一般通話、SMS簡訊及110、119維持正常，高流量網路服務可能明顯變慢。

## 8/13行動網路降速幾點開始？哪些縣市受影響？

北部行動網路降速演練時間為2026年8月13日（星期四）下午2時30分至3時，共30分鐘，實施範圍包括：

- 台北市
- 新北市
- 基隆市
- 桃園市
- 新竹縣
- 新竹市
- 宜蘭縣

今年城鎮韌性防空演習首度加入大規模行動網路降速演練，中部7縣市已於8月10日完成首波測試，北部則於8月13日接續實施。政府表示，演練目的在模擬重大災害、大規模網路攻擊等極端情境，測試行動通訊受限時的應變與備援能力。

## 會完全斷網嗎？哪些手機功能受影響？

不會完全斷網，主要是降低4G、5G行動網路速度。行政院與NCC表示，語音通話、簡訊、110與119緊急報案、災防告警細胞廣播（CBS）等基本通訊功能將維持正常，但需要較多數據流量的服務可能變慢或連線不順。

| 手機功能 | 演練期間可能影響 |
| --- | --- |
| 一般語音通話 | 維持正常 |
| 110、119緊急電話 | 維持正常 |
| 手機簡訊SMS | 維持正常 |
| 災防告警CBS | 可正常接收 |
| 影音串流 | 可能變慢或無法順利載入 |
| 視訊通話 | 可能變慢或連線不順 |
| 行動支付 | 可能受到影響 |
| 雲端同步、備份 | 可能變慢 |
| 大型檔案下載、傳輸 | 可能明顯變慢 |

政府所稱可維持的簡訊與文字傳輸，不代表LINE、Messenger等第三方App一定能正常使用。這些App仍需透過行動數據連線，實際情況可能受到降速程度影響。

## 8/10中部實測怎麼樣？

8月10日下午，中部7縣市率先進行30分鐘行動網路降速。行政院表示，警察、消防、緊急醫療等重要公共服務均正常運作，下午3時演練結束後相關系統也恢復正常。

不過，一般民眾的體感明顯不同。中央社採訪發現，嘉義有人使用LINE傳照片時幾乎無法完成；南投有人手機顯示4G滿格，網頁卻打不開，也有民眾反映LINE、網頁及行動支付程式卡頓；台中則有手遊無法正常載入。另一方面，電話通訊仍可正常使用。

這些是不同地點與使用者的實際回報，不代表8月13日每支手機或每個App都會出現相同狀況，但顯示降速體感可能比單純網頁載入稍慢更明顯。若有重要工作、付款或資料傳輸需求，最好不要把關鍵操作留到演練時段。

## 還要配合防空避難嗎？

要。行動網路降速只是城鎮韌性防空演習的一部分。8月13日下午2時30分至3時，北部地區同時進行警報發放、疏散避難、交通管制及災害救援等演練。民眾聽到防空警報後，仍須依警察、民防人員或所在場所工作人員指示避難。

國防部全民防衛動員署指出，演習區域內的政府機關、學校、公司、團體及一般民眾若未依規定配合演習命令與管制，各地方政府可依《民防法》第25條裁處新台幣3萬元以上、15萬元以下罰鍰。

台北捷運在演習期間列車及車站仍正常運作，但到站旅客須依工作人員引導進入適當區域避難，並非下車後就能直接離開車站。

## LINE還能用嗎？Wi-Fi會一起降速嗎？

官方沒有保證LINE等第三方通訊App在演練期間能正常使用。LINE文字、照片、影片、語音或視訊都需要網路，所需流量不同，實際影響依當下行動網路狀況而異。緊急聯繫可優先使用一般語音通話或SMS簡訊，照片、影片、視訊及大型檔案則建議避開演練時段。

這次演練主要針對4G、5G行動通訊網路，不是一般固定寬頻。家中或辦公室透過固定寬頻連接的Wi-Fi，可作為備援方式；但若Wi-Fi是另一支手機分享的行動熱點，底層仍使用4G或5G，因此同樣可能受到降速影響。

## 行動支付會不能用嗎？

可能受到影響，但不能直接說所有行動支付都會失效。行政院將行動支付列為降速時可能受影響的服務之一；NCC也建議，有重要線上交易或行動支付需求的民眾提前或延後辦理。

不同付款服務的運作方式不完全相同，官方未逐一保證特定支付服務一定可以使用。最簡單的做法是避免把手機當成唯一付款方式，外出可另外準備：

- 實體信用卡
- 悠遊卡、一卡通等交通票卡
- 適量現金

## 搭捷運、台鐵或飛機會受影響嗎？

交通運輸本身大致維持正常，但手機購票、電子票證或部分聯外交通可能受影響。

台鐵表示，演習期間列車照常行駛，車站售票及進出閘門維持正常，但透過行動網路使用「台鐵e訂通」App時，可能遇到登入、身分驗證、電子車票下載、線上退票或改票無法即時完成等情形。

台北捷運列車及車站正常運作，但若降速導致QR乘車碼或手機QR單程票無法使用，可改用儲值卡、信用卡或購買單程票。

桃園機場方面，8月13日航班起降及機場捷運維持正常，但演習30分鐘內聯外接駁交通暫停發車。需要搭車或搭機的民眾，最好提前下載電子票券、截圖必要資料，準備實體票卡，並預留充裕交通時間。

## 演練前要準備什麼？

- 重要檔案先下載到手機或電腦。
- 線上會議、影音及大型檔案傳輸避開下午2時30分至3時。
- 重要線上交易、行動支付提前完成。
- 高鐵、台鐵、機票或活動票券先下載或截圖。
- 提前查詢並截圖附近防空避難設施。
- 外出準備信用卡、交通卡或適量現金。
- 有重要上網需求時優先使用固定寬頻Wi-Fi。
- 緊急聯繫改用一般語音通話或SMS簡訊。
- 演練後仍無法上網，可開啟再關閉飛航模式，或重新啟動手機。

## 常見問題

### 8月13日北部行動網路降速多久？

下午2時30分至3時，共30分鐘。

### 手機會完全沒有網路嗎？

不會完全斷網，但4G、5G速度會降低，高流量服務可能難以使用。

### LINE文字訊息一定能傳嗎？

不一定。LINE仍依賴行動數據，官方僅確認一般語音通話與SMS簡訊等基本通訊維持運作。

### 家用Wi-Fi會降速嗎？

固定寬頻Wi-Fi不在主要降速範圍；手機分享的行動熱點則可能受到影響。

### 下午3時後仍無法上網怎麼辦？

可先開啟再關閉飛航模式，或重新啟動手機，讓裝置重新建立網路連線。
